# مركز قيادتي الشخصي 🕌📋

لوحة تحكم شخصية شاملة لتنظيم اليوم: العبادات (صلاة، أذكار، مسبحة، قرآن)، المهام، المشاريع، الأفكار، العادات، التقارير والتقويم.

## التشغيل

افتح `index.html` في المتصفح مباشرة — لا يحتاج سيرفر ولا إنترنت (عدا جلب مواقيت الصلاة أول مرة عبر Aladhan API).

أو للنشر على GitHub Pages: فعّل Pages من Settings → Pages → اختر branch `main` — وسيعمل الموقع فورًا لأنه static بالكامل.

## المميزات

- 📊 لوحة تحكم: التاريخ الهجري/الميلادي، نسبة الإنجاز، الصلاة القادمة بعدّاد حي
- 🕌 الصلاة: مواقيت حقيقية (مدينة/GPS)، طرق حساب، فروقات يدوية، تسجيل يومي
- 🌿 الأذكار: 8 تصنيفات + عدّادات + مخصص
- 📿 المسبحة: عدّاد + سجل جلسات
- 📖 القرآن: ورد يومي + تسجيل (تلاوة/حفظ/مراجعة/استماع)
- ✅ المهام: أولويات، حالات، تكرار، checklist، سحب وإفلات
- 🚀 المشاريع: نسبة تلقائية + مراحل
- 💡 بنك الأفكار: تحويل لمهمة/مشروع
- 🗓️ يومي + 🔥 عادات + 📊 تقارير + 📅 تقويم + 🔔 تنبيهات

## الخصوصية

البيانات محفوظة في `localStorage` على جهازك فقط. للنسخ الاحتياطي استخدم زر التصدير في القائمة الجانبية.
